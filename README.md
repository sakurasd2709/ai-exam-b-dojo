*(PCでもスマホでも、ブラウザで開くだけで即座に学習可能＆進捗が自動同期されます)*

## 🚀 主な機能と特徴

### 1. ☁️ PC・スマホ間 ゼロ設定クラウド自動同期 (Cloud Sync)
- **合言葉不要の完全自動同期**: 合言葉やコードを入力しなくても、標準でクラウドストレージと連携。PCで解いた続きを、外出先でスマホから開くだけで即座に再開できます。
- **リアルタイム双方向同期**:
  - **自動保存（プッシュ）**: 問題に回答した瞬間、および問題番号を切り替えた際にバックグラウンドで自動同期。
  - **自動復元（プル）**: サイトを開いた際、またはスマホで画面ロック解除や他アプリからタブに復帰した際（`visibilitychange`）に最新データを自動同期。
  - **前回の続きから自動再開**: クラウドに保存された直前の設問番号（`lastQuestionId`）へ自動ジャンプ。サイドバーの「▶ 前回の続きから解く」ボタンからもワンタップで移動可能。
- **データ移行・バックアップ**:
  - 複数人で個別に利用したい場合の「カスタム合言葉設定」。
  - クリップボード経由の「進捗コード（Base64）」コピー＆ペースト。
  - バックアップ用の「学習履歴JSON」エクスポート＆インポート。

### 2. 本番忠実な模擬試験モード (30問 / 40分)
- **CBT本番完全シミュレーション**: 公式試験（全30問・制限時間40分・正答率70%合格ライン = 21問以上で合格）に準拠。
- **実時間同期タイマー (Drift-Free)**: バックグラウンド遷移時でもズレない `Date.now` 基準の実時間カウントダウンタイマー。
- **出題プール固定化**: 模試開始時に専用プール（`examQuestionPool`）を抽出し、セット切替時の誤リセットを防止。
- **合格判定サマリー**: スコア・正答率・7分野別レーダーチャートを表示し、間違えた問題だけの復習モードへ即座に移行可能。

### 3. 公式テキスト（全7講）完全網羅の90問データベース
- **公式まとめ◯✕チェック（全問収録）**: 動画各講末の確認問題をすべて収録。
- **各講義の重要概念・計算・モデル問題を網羅**:
  - **第1講: モデルの設計と活用までの流れ** (12問)
  - **第2講: データの入出力とタスク** (12問)
  - **第3講: モデルの評価指標** (14問)
  - **第4講: 画像データの取り扱い** (14問)
  - **第5講: 数学的な表現に慣れる** (14問)
  - **第6講: 計算量の基礎** (12問)
  - **第7講: 開発と活用に向けて** (12問)
- **多彩な出題形式**: 単一選択、○×問題、順序並べ替え（ドラッグ＆ドロップ）、マッチング、Hotspot（Yes/Noテーブル）。

### 4. 深層3層構造化解説 ＆ 公式講義動画直通リンク
すべての設問に以下の構造化カード解説を用意：
- 📖 **【基本解説・設問の背景】**: 概念の直感的解説・身近な例え
- ✅ **【正解のポイント・仕様上の根拠】**: なぜその選択肢が正しいのか、定義・数式・スライドの根拠
- 🚨 **【なぜ他の選択肢は誤りなのか？（罠ポイント・誤答分析）】**: 各誤答選択肢の誤り理由と初心者が陥りやすい引っかけポイント
- 🎬 **【公式教材 YouTube解説動画】**: 該当するYouTube動画（該当チャプター）への直通ボタンを配置。

### 5. 📊 7大分野別 弱点分析 & レーダーチャート
- ヘッダーの「**📊 弱点分析**」ボタンから、HTML5 Canvasによる7角形レーダーチャートで現在の習熟度をリアルタイム可視化。
- **高DPI & ラベル自動調整**: スマホやRetinaディスプレイ（`devicePixelRatio`）に対応し、文字欠けを起こさない動的テキスト整列を搭載。
- 分野ごとの正答率・回答数を一覧表示し、「**この分野を特訓 🎯**」ボタンから苦手トピックだけをワンクリックで集中演習可能。

### 6. 🎬 公式動画カタログモーダル (全41講)
- ヘッダーの「**🎬 公式動画カタログ (41講)**」ボタンから、全41本の講義動画を章ごとに一覧表示。
- キーワード検索機能（例: 「内積」「ILSVRC」「オーダー」「損失関数」）により、見たい講義動画を即座に探して視聴可能。

### 7. 10問セット演習 (全9セット) ＆ 🎲 ランダム10問ミニテスト
- スキマ時間の学習に最適な「第1セット (1〜10)」〜「第9セット (81〜90)」。
- 全問からランダムに10問を抽出するミニテスト。
- 10問完了時にサマリーモーダルが表示され、「次のセットへ進む」「間違えた問題だけ再挑戦」をスムーズに実行可能。

### 8. 連続学習記録（ストリーク🔥）＆ 学習進捗の自動保存
- 学習を継続すると「🔥 連続学習記録: N日連続！」がカウントアップ。
- 本日の学習問数もリアルタイム表示（再採点時の二重計上防止ガード機能付き）。
- ブラウザの `localStorage` により、オフライン時でも学習履歴・正誤結果・ブックマークが安全に自動保存されます。

### 9. スマホ・PC完全両対応 ＆ 完全オフライン単一HTML版
- スマホ（900px以下）でも快適に操作できるドロワー型サイドバー（アコーディオン）と最適化されたタッチ操作領域。
- ビルドスクリプトにより生成された `AI実装検定B級_過去問演習_スマホ・PC用.html` は、外部通信不要でブラウザで直接ダブルクリックするだけで完全オフライン動作します。

### 3. ビルド＆テストパイプラインの実行

本プロジェクトのスクリプトは、実行元のディレクトリ（プロジェクトルート、または `scripts/` 直下）に依存せず、常にプロジェクトルートを自動認識して安全に実行されます。

```bash
# 1. 全問マスターデータ（data/questions.json & questions.js）の統合・再構築
python scripts/assemble_questions.py

# 2. 完全オフライン単一HTMLファイルの自動生成
python scripts/build_single_file.py

# 3. 総合品質保証（QA）テストスイートの実行 (全90問の整合性・解説・URL検査)
python scripts/qa_test_suite.py
```

※npm 経由でも実行可能です：
```bash
npm run assemble      # 設問データ統合
npm run build:single  # 単一HTML生成
npm test              # QAテスト実行
```

---

### 4. Vercel へのデプロイとクラウド同期の設定

Vercel にデプロイすることで、Serverless Function (`api/sync.js`) を介したマルチデバイス自動同期が利用可能になります。

1. **GitHub リポジトリの準備**:
   本リポジトリをご自身の GitHub アカウントにプッシュまたはフォークします。
2. **Vercel プロジェクトのインポート**:
   Vercel ダッシュボードから本リポジトリを「Import」します（Framework Preset: `Other`）。
3. **環境変数の設定 (オプショナル)**:
   自分専用のストレージに分離したい場合、Vercel の `Settings -> Environment Variables` に以下を設定します（詳細は `.env.example` を参照）：
   - `GITHUB_TOKEN`: GitHub Personal Access Token (`gist` 権限)
   - `GIST_ID`: 進捗JSONを保存する秘密GistのID

※環境変数を設定しなくても、組み込みのフォールバック定義により自動的に同期機能が稼働します。
