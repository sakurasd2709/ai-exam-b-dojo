# AI実装検定® B級 過去問・演習道場 🥋 (公式テキスト完全準拠)

AI実装検定® B級（AI Implementation Examination Grade B）の一発合格を目指す学習者のための、公式教材（YouTube『中学生から分かるAI入門講座』全41講）に完全準拠した本格的な過去問演習・模擬試験Webアプリケーションです。

---

## 🚀 主な機能と特徴

### 1. 本番忠実な模擬試験モード (30問 / 40分)
- **CBT本番完全シミュレーション**: 公式試験（全30問・制限時間40分・正答率70%合格ライン = 21問以上で合格）に準拠。
- **40分カウントダウンタイマー連動**: 残り時間をリアルタイム表示し、試験終了後に一括採点＆合否判定。
- **合格判定サマリー**: スコア・正答率・分野別レーダーチャートを表示し、間違えた問題だけの復習モードへ即座に移行可能。

### 2. 公式テキスト（全7講）完全網羅の90問データベース
- **公式まとめ◯✕チェック（全問収録）**: 動画各講末の確認問題をすべて収録。
- **各講義の重要概念・計算・モデル問題を網羅**:
  - **第1講: モデルの設計と活用までの流れ** (12問)
  - **第2講: データの入出力とタスク** (12問)
  - **第3講: モデルの評価指標** (14問)
  - **第4講: 画像データの取り扱い** (14問)
  - **第5講: 数学的な表現に慣れる** (14問)
  - **第6講: 計算量の基礎** (12問)
  - **第7講: 開発と活用に向けて** (12問)
- **多彩な出題形式**: 単一選択、○×問題、順序並べ替え（ドラッグ＆ドロップ）、マッチング、Hotspot（Yes/Noテーブル）。

### 3. 深層3層構造化解説 ＆ 公式講義動画直通リンク
すべての設問に以下の構造化カード解説を用意：
- 📖 **【基本解説・設問の背景】**: 概念の直感的解説・身近な例え
- ✅ **【正解のポイント・仕様上の根拠】**: なぜその選択肢が正しいのか、定義・数式・スライドの根拠
- 🚨 **【なぜ他の選択肢は誤りなのか？（罠ポイント・誤答分析）】**: 各誤答選択肢の誤り理由と初心者が陥りやすい引っかけポイント
- 🎬 **【公式教材 YouTube解説動画】**: 該当するYouTube動画（該当チャプター）への直通ボタンを配置。

### 4. 📊 7大分野別 弱点分析 & レーダーチャート
- ヘッダーの「**📊 弱点分析**」ボタンから、HTML5 Canvasによる7角形レーダーチャートで現在の習熟度をリアルタイム可視化。
- 分野ごとの正答率・回答数を一覧表示し、「**この分野を特訓 🎯**」ボタンから苦手トピックだけをワンクリックで集中演習可能。

### 5. 🎬 公式動画カタログモーダル (全41講)
- ヘッダーの「**🎬 公式動画カタログ (41講)**」ボタンから、全41本の講義動画を章ごとに一覧表示。
- キーワード検索機能（例: 「内積」「ILSVRC」「オーダー」「損失関数」）により、見たい講義動画を即座に探して視聴可能。

### 6. 10問セット演習 (全9セット) ＆ 🎲 ランダム10問ミニテスト
- スキマ時間の学習に最適な「第1セット (1〜10)」〜「第9セット (81〜90)」。
- 全問からランダムに10問を抽出するミニテスト。
- 10問完了時にサマリーモーダルが表示され、「次のセットへ進む」「間違えた問題だけ再挑戦」をスムーズに実行可能。

### 7. 連続学習記録（ストリーク🔥）＆ 学習進捗の自動保存
- 学習を継続すると「🔥 連続学習記録: N日連続！」がカウントアップ。
- 本日の学習問数もリアルタイム表示。
- ブラウザの `localStorage` により、学習履歴・正誤結果・ブックマークが安全に自動保存されます。

### 8. スマホ・PC完全両対応 ＆ 完全オフライン単一HTML版
- スマホの縦画面でも操作しやすいレスポンシブデザイン（タップしやすいボタン配置、並べ替え用の上下ボタンなど）。
- ビルドスクリプトにより生成された `AI実装検定B級_過去問演習_スマホ・PC用.html` は、外部通信不要でブラウザで直接ダブルクリックするだけで完全オフライン動作します。

## 💻 使い方・クイックスタート

### 1. ブラウザで直接開く場合 (オフライン単一ファイル)
- `AI実装検定B級_過去問演習_スマホ・PC用.html` をお好みのブラウザ（Chrome, Edge, Safari等）でダブルクリックして開くだけで、インストール不要ですぐに学習を開始できます。

### 2. ローカル簡易Webサーバーで起動する場合
```bash
# ワークスペースディレクトリに移動
cd AI実装検定B級

# Pythonの簡易HTTPサーバーを起動
python -m http.server 8080
# => ブラウザで http://localhost:8080/ にアクセス
```

### 3. ビルドスクリプトの実行
```bash
# 全問マスターデータ（data/questions.json & questions.js）の再構築
python scripts/assemble_questions.py

# 単一HTMLファイルのビルド
python scripts/build_single_file.py

# 総合品質保証テストスイートの実行
python scripts/qa_test_suite.py
```
